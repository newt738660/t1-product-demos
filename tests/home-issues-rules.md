# 首页问题规则（2026-09-25）

本次只优化首页提醒，沿用全平台 card、badge、btn、icon-btn 和主题变量，不改变通知分类、报表口径、归档规则。首页已有投放时移除顶部新建和联系运营；空账户引导保留，业务相关的联系运营仍保留。

| 类别 | 触发情况 | 对象与动作 | 忽略 |
|---|---|---|---|
| 资金与预算 | 余额耗尽且存在排期内启用RTB计划 | 账户；查看资金 | 不允许 |
| 资金与预算 | 余额按近7个完整日平均消耗预计不足2天 | 账户；查看资金 | 允许 |
| 资金与预算 | 排期内RTB计划总预算耗尽 | 计划名称、ID；进入该计划编辑（只读用户查看计划） | 不允许 |
| 创意审核 | 排期内启用组全部未归档创意被驳回 | 广告组名称、ID、所属计划；进入该组查看全部创意，不随意进入第一条 | 不允许 |
| 投放准备 | 已到开始时间的启用组没有未归档创意 | 广告组及所属计划；RTB进入创建创意，CPD进入组详情 | 不允许 |
| 投放准备 | 两天内开始的启用组没有未归档创意 | 同上，附开始日期 | 允许 |
| 系统与数据 | 启用计划状态同步失败 | 单独状态提示；计划名称、ID，联系运营 | 不提供忽略 |

已影响投放优先于临近风险；类别标签不表示紧急度。系统提示与待处理计数分开。主列表默认3项，数量与原地展开/收起相邻；已忽略也在卡片内查看和恢复，不新增弹窗。

忽略保存在当前浏览器，按广告主和当前成员资料隔离，不代表生产端持久化已接入。只隐藏本次风险，不改投放、审核或通知状态。保存业务变化或读取首页时清理已解除及已升级事项的忽略标记，风险变阻断后重新出现，解决后再发生也重新提示。跨设备和未被Demo观察到的服务端状态变化，生产接入须以问题实例标识实现。

使用已有Mock案例覆盖预算耗尽、驳回、余额风险、即将开始缺创意、状态延迟。通过 tests/home-issues.cjs 验证展开、忽略恢复刷新、升级、解除再发生、成员隔离、动作落点、通知关闭、报表入口及移动端。

## 紧凑布局修订

收到模块过高、按钮参差反馈后，桌面端改为固定的类别／问题与对象／操作三列；标题与切换、计数、展开入口合并一行。摘要两行，ID、完整所属关系和解释默认收起，点“详情”在本条下面展开。系统提示取消额外标题行。1440px视口默认3条待处理加1条状态提示，模块实测317px；回归检查操作列横坐标相同。窄屏按同一顺序换行，并保留原忽略、恢复和升级规则。
