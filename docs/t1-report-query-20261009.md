## 历史查询与下载入口：暂不建设，保留讨论

两类需求应分开：

1. 最近查询：记录日期、条件、报告类型与查询时间，点击后回填，再执行查询。重新执行可能获得更新后的数据，不是还原旧结果。高频重复查相同范围时才值得加；优先轻量最近查询，不新增导航模块。
2. 下载记录：记录生成状态、条件、发起人、截止时间、文件有效期，支持下载当时的文件。需要异步大文件、离开页面后继续生成或找回旧文件时价值更明确；必须有后端任务、存储与权限支持。
3. 查询条件记录不是审计凭据。若要复现某一时刻数字，需要结果快照／原文件及口径版本，不能用“再查一次”代替。

首版采用直接下载，无历史查询和下载记录按钮，避免将未定功能混入评审。查询上下文保留解决本次操作中来回跳转，不宣称历史追溯已完成。
