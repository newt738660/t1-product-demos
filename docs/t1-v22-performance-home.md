# V2.2 首页：投放表现与变化（2026-10-02 讨论稿）

## 本轮可评审内容

- 仅调整 `versions/v2.2`；冻结评审基线及原版不变。
- 首页为「立即处理 → 投放表现与变化 → 轻量业务入口」。暂不保留未确认的计划状态、近期排期模块；未开户、审核中、无投放和财务角色沿用原有首页。
- 创意、广告组、广告位、计划四个维度直接平铺，无需切换维度，展示 CTR 最高、最低、较前期上升最多、下降最多。只有满足条件的结果才出现，不强凑四条。
- 同一数据源生成首页结果、对象比较表、逐日趋势及原数据报表。点击结果保留投放类型、计划、组、广告形式、日期和对象；明细属于数据报表下的比较视图。
- 只报告曝光、点击和点击率的实际比较，不推断受众耗尽、创意疲劳或转化收益，不提供自动调价、换素材建议。没有加入时段、人群或变更事件等尚未确认的数据能力。

## 演示口径（并非生产承诺）

- 本演示采用最新有数据日期结束的7个完整日，与此前7日比较；页面明确列出日期和UTC，正式业务时区与SSP对齐。
- 创意限定同广告组；广告组限定同计划；所有维度区分RTB/CPD与广告形式。首页自动给出范围：创意优先展示有至少两个合格对象且合格对象本期总曝光最多的广告组；广告组按同样规则选计划。广告位与计划展示该投放类型、该形式下的全部对象；每块直接写明范围，不混排不同广告形式。默认形式沿用该范围事实记录中的首个形式；此自动范围规则为演示方案，待评审。
- CTR = 总点击 / 总曝光；纵向按百分点变化排序。前期为0不算相对增幅，无曝光用“—”；不平均每日比率。
- 每期曝光至少1,000为暂定演示门槛，待真实数据量验证，不代表统计显著。零点击不排除；数据延迟不入选；单一对象不评高低；变化不足0.01个百分点不选升降，持平不造榜。
- 原始低样本数据仍可查；延迟日期不填零。归档或暂停不抹去历史，创意ID下的多个版本暂合并，不能解释为单素材效果。
- 两期比较不是持续上升／下降的证据；趋势页附14天逐日CTR与曝光、点击，供用户自行判断。RTB花费仅向有财务权限的人显示；CPD不分摊合同金额。
- 仅补充内置Mock的点击走势，未接生产统计、资金或审核服务。SSP的逐日、对象、广告位维度数据支持情况仍待确认。

## 同步已确认的立即处理规则

- 可用余额 / 有效日预算合计 < 7天，账户合并一条；等于7天不提示。无可投路径不计预算，余额不足自身不作为排除条件，有效合计0时不算天数。
- 演示预算算法：可投组日预算合计，受计划日上限约束，不将两层相加；有组缺日预算时采用已知计划上限。无可靠预算不推测。正式层级、库存、时段约束需SSP确认。
- 每条被驳回创意均提示；重新送审进入审核中即退出待办，旧版本继续生效的情况也单独判断。已读不解除业务事项。
- 非阻断余额风险保留个人忽略、查看和恢复；风险升级为余额耗尽恢复提醒。真实阻断不允许忽略。所有问题原地展开，不新增列表浮层。

## 评审路径

1. 打开V2.2首页，默认欧洲秋季拉新广告组有两条创意，一升一降。
2. 点击「查看对比」查对象数据；点击「查看趋势」查14日曲线与逐日明细。
3. 直接向下浏览广告组、广告位、计划结果，核对各块范围与点击落点；唯一的投放类型选择可切CPD，不用逐维度切换。
4. 仅评审模式的左下角「演示工具」提供小样本、单一创意、恢复比较示例，普通广告主界面不出现这些按钮。
5. 展开「立即处理」核对账户级预算依据与驳回创意入口。

本轮是可操作方案，正式阈值、比较范围与生产数据条件尚未定稿，不将本稿视为新增功能已开发上线。
