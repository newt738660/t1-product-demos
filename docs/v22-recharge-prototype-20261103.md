# V2.2 充值原型 · 2026-11-03

入口：首页右上角「充值」或左侧「财务管理」→「充值」。评审直达链接参数：`?demo=1&review=1&case=finance&recharge=1`。

## 本次交互

- 同页两部分：收款信息／转账指导；实际金额、付款凭证、备注。已有转账可直接填写第二部分。
- 广告主名称和ID固定为当前关联对象。收款地址为不可付款占位，二维码仅占位，不可扫描。
- 凭证JPG/PNG，每张5MB、最多10张，可添加和移除。Demo只保留本浏览器缩略图，不上传服务端。
- 提交生成同一浏览器的Mock申请，状态为处理中，不增加余额。
- 左下角收起的演示工具可模拟SSP：仅核实、未通过、实际入账。仅实际入账才更新余额；同一结果不重复加款。
- 未通过展示原因，补资料重提同一申请并保存历史，不要求再次付款。
- 收款配置缺失时不展示可付款地址；已付款客户仍可提交凭证。
- 未新增邮箱验证强制门槛，沿用广告主关联和财务权限约束。

## 不作为业务定论

USDT是付款币种样例，账户USD沿用原Demo；两者分别展示，不自动按1:1计算。模拟入账时手填SSP实际入账额。正式币种、网络、地址/二维码来源、是否按广告主独立配置、付款方地址/交易编号/转账时间必填要求、审核是否自动加款、金额差异与跨端重复报备处理均需SSP确认。

现有消耗记录保留，本次不扩展报表，不创建真实SSP后台或支付通道。余额及状态变化仅为Mock，不代表真实打款/审批/到账。
