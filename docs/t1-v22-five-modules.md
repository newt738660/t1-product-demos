# T1 V2.2 五模块交互稿

本稿是可操作的前端方案，不代表生产开发或后台联调完成。仅修改 `versions/v2.2/`；2026-09-29冻结基线保持不变。

评审地址：`t1-p0-advertiser-platform/versions/v2.2/dsp.html?demo=1&review=1`。
左下角展开“演示工具”：切换首页样例、模拟成员视角，或模拟平台处理结果。普通视角不显示该面板。

## 1. 充值与财务

- 导航：财务管理。余额、待审核金额、已提供周期的RTB消耗。
- 发起充值：金额、付款方式、付款凭证、备注；校验后提交。
- 待审核不加余额；可查看凭证、状态、处理意见和时间。
- 驳回后修改并重提，同一个单号保留；审核通过只加款一次。
- 待审核可撤销；明确撤销申请不等于退款，实际转账需联系运营。
- 充值记录按状态、单号查询；消耗记录按UTC日期、计划查询，支持归档计划、跳转对应报表与导出CSV。
- 消耗CSV按日期＋计划聚合，与同条件页面／报表金额一致。CPD合同费用不混入RTB钱包。
- 平台审核结果只能从左下角“模拟充值审核结果”触发，正式广告主页面没有自审按钮。

## 2. 首页与通知

- 未关联、开户／绑定审核中、驳回、已关联无投放、已有投放、仅RTB／CPD、余额不足、通知为空等样例。
- 邮箱待验证、存量账号待确认状态提供优先处理提示和落点。完成验证后继续投放／充值。
- 已有投放沿用当前事项、计划状态、近期排期结构，处理入口可进入对应计划、财务或指南。
- 财务角色使用资金工作台，不显示投放详情。只读角色不能执行投放修改。
- 铃铛最近5条；通知中心按分类、已读过滤；事件详情区分“当时发生”与“当前情况”。
- 充值提交／到账／驳回／撤销、开户绑定结果、成员加入与权限变更、账号核验进展等生成可跳转事件。
- 同对象、同次提交、同结果去重；已读状态按模拟成员隔离；读通知不关闭业务问题。
- 财务通知限管理员与财务；组织通知限管理员；本人账号事件限本人；缺少权限不能访问对应对象。
- 左下角“首页与通知规则”给出策略说明，明确不是产品配置中心。

## 3. 基础组织权限

单组织、单关联广告主。固定管理员、投放操作员、财务、只读四类角色，不含自定义角色或多工作空间切换。

- 组织与成员：管理员查看成员和操作记录；其他成员仅查看自己的组织关系。
- 邀请：姓名、邮箱、角色 → 待接受；重复邀请被拦截。
- 接收页：确认组织和角色后接受或拒绝；过期／撤销邀请不能接受，可重新邀请。
- 接收页预览仅在演示区提供，正式产品应由邮件进入并校验受邀邮箱。
- 调整角色后权限生效；移除成员保留业务历史。
- 唯一管理员不能直接移除；确认交接后目标成员成为管理员，原管理员转只读。
- 同时限制导航、入口和主要提交／修改动作；前端演示权限不等于服务端鉴权实现。

## 4. 帮助与联系运营

帮助中心提供搜索及8篇可阅读指南：RTB、CPD、开户绑定、财务、报表、创意审核版本、成员权限、账号重置。

- 首页介绍卡 → 对应指南 → 创建、查询、联系运营等下一步。
- 每篇指南有快速说明浮层、完整落地页与下一步动作。
- 联系运营提供可编辑咨询模板、复制及现有商务群联系路径；没有虚构联系人或伪造工单提交。

## 5. 账号流程和存量账号重置

入口：左侧“账号与验证”，登录页“忘记密码”“存量账号重置”。不新增账号菜单或工作空间切换。

- 注册：填写基本信息 → 邮箱验证 → 创建未绑定账号 → 原开户／绑定流程。
- 邮箱验证：待验证、申请已创建、链接失效、重试、完成；Demo不发送邮件。
- 邮箱可用：邮箱确认 → 验证 → 设置新密码 → 完成 → 重新登录。
- 邮箱不可用：旧账号、目标邮箱、归属说明 → 人工核验 → 驳回补充重提／通过 → 验证目标邮箱 → 设置密码 → 重新登录。
- 重置更新登录信息，保留广告主关联、组织关系、余额和历史投放。
- 密码仅做页面校验，不存储密码。真实邮件、身份核验、密码服务和会话失效机制未接入。
- 人工核验结果在明确标注的演示工具里模拟，不能将“模拟通过”当作真实身份认证。

## 评审需确认的方案假设

1. 四种固定角色的具体权限；非管理员仅看自己关系、交接后原管理员转只读，均为当前方案。
2. 充值最低50美元、两位小数、凭证2MB、线下／USDT示例、待审核撤销规则须和实际SSP及运营流程确认；没有新增线上支付能力。
3. 邀请7天有效、密码至少8位、验证演示重试10秒均为样例参数，不是已确认生产规则。
4. 邮箱未验证／存量确认未完成时拦截新建投放和充值的范围、人工核验材料、实际账号匹配规则，需业务和研发细化。
5. 实际通知触发接口、数据更新频率、保留期、运营联系入口和邮件服务待对接。
6. 新注册带邀请码时本稿提示先验证邮箱，再在登录后原关联流程使用；不伪造邀请码有效性。

## 不在本轮

真实充值、真实审批、真实邀请邮件、后端权限验证、生产账号重置；退款、发票、授信和复杂结算；多组织／多广告主切换、自定义角色、多级部门；独立创意仓库；API for AI Agent实现。
